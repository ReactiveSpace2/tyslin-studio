# Agent heads

Mascot head set for agent and assistant avatars (owner-supplied, 5 Nov 2026). Ids and labels are in
`src/shared/heads.ts`; the same files are copied to `src/renderer/src/assets/heads/`.

**Temporary cut-outs.** These 256 px PNGs were cut out of a single 991×1088 JPEG sheet whose
transparency checkerboard was painted in. Edges are slightly soft, the glows (`idea`, `globe`) are
blotchy, and `calm` lost the thought bubble it had on the sheet. Replace each file with the original
transparent PNG (512 px or larger) under the same name, in both folders; no code changes needed.

Never recolour, stretch or redraw the heads.
